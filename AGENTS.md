Create a Teenage Engineering style software wavetable synthesizer using the JUCE Framework based on the rough and incomplete ui Mockup in this Folder (Mockup.png). The Mockup is very incomplete, so get creative and "fill in the gaps", for example lots of buttons don't have any function yet. Feel free to adjust the layout and functionality. The synth should be a digital prototype of a hardware synthesizer, so make sure the "displays" have an authentic hardware display feel and everything behaves like it would on a hardware synth. The modulation matrix is inspired by arturia synthesizers like the polybrute and matrixbrute.

For now, only create a standalone Version, a VST Version should follow later. The standalone Version should listen to all midi Inputs to Keep Things simple. More features, like different oscillator types (e.g. classic analog, physical moddeling etc.) should be added later.
